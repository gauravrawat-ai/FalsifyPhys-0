# NanoForge-C2

Evaluator-first protocol planner for C2 mechanosynthesis on H:Si(100).

This module separates two interfaces:

1. Molecular/protocol output viewer: `web/nanoforge-c2`.
2. ShinkaEvolve code-search outputs: `results/nanoforge_c2_headless`.

The ShinkaEvolve code UI must not be confused with molecule outputs.
